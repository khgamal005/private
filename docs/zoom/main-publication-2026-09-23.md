## التحقق اليدوي من هوستينجر

في لوحة موقع أودير `odeir.com`، راجع Deployments وسجل البناء، ثم سجّل:

| الدليل | المطلوب |
|---|---|
| المصدر | `Marktonesa/marktone-platform-control` والفرع `main`، مع SHA المطابق لـGitHub بعد هذا التحديث |
| الحالة | نجاح النشر ووقت اكتماله؛ حالة GitHub Quality ليست بديلًا |
| البناء والتشغيل | Node24، تثبيت lockfile، نجاح `npm run build` وتشغيل Next.js بلا restart loop أو خطأ إعداد |
| سلامة التطبيق | الصفحة العامة وتسجيل الدخول، ثم تدفق مأذون محدود؛ لا اختبار كتابة على ريف |
| طبقات التكامل | توثيق حالة24migration و`zoom-connect` والعامل/الجدولة والرايات كلٌّ على حدة |
| حدود النتيجة | ظهور الشاشة لا يثبت ربط Zoom أو استقبال أحداثه أو حضورًا معتمدًا؛ لا تفعيل قبل حسم المتطلبات الخارجية |

لم يتوفر إثبات جديد من hPanel عند إعداد سجل النشر: بقي الوصول السابق عند Cloudflare security verification، ولا موصل Hostinger متاح. لذلك يلزم تسجيل الدليل اليدوي، أو إتاحة اتصال مأذون للوحة، دون إرسال كلمات مرور أو رموز سرية في المحادثة. لا حذف لموقع قائم ولا تغيير DNS ولا تشغيل Redeploy قبل معرفة حالة البناء الذي قد بدأ تلقائيًا.
