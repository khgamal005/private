# مصفوفة الاحتفاظ والحذف — قرار الإطلاق ما زال مشروطًا

الفصل المحلي، إيقاف التوزيع، إلغاء تفويض التطبيق، وطلب الحذف إجراءات مختلفة. لا حذف مالي أو جماعي للدفعات بسبب Zoom. **لا اعتماد نهائي لسياسة قانونية أو مدة نسخ احتياطية في هذه الحزمة.** يلزم مالك سياسة البيانات قبل الطرح الخارجي.

| المصدر/النسخة | الموجود فعليًا | عند الإلغاء/انتهاء الإتاحة | الإثبات والحد |
|---|---|---|---|
| access/refresh/روابط شخصية | Vault لكل اتصال/رابط/مشارك | حذف secret وتصفير مراجعها | lifecycle وadvanced؛ Vault fixture محلي، تشفير المنصة الحقيقي يحتاج تحقق بيئة |
| Webhook | projection محدودة في events؛ لا نسخ الجسم الكامل في log | حذف أحداث الاتصال | lifecycle؛ ACK لا يعني معالجة كاملة |
| فترات/هويات حضور Zoom | intervals/instances وregistrations | حذف الفترات، تنقيح UUID/بريد/معرفات وروابط المزود | lifecycle/advanced؛ غياب الدليل لا يثبت غياب طالب |
| مضيف/انشغال/ربط بديل | hosts/host_instructors/busy_windows | إزالة بيانات مزود، إيقاف الروابط، حذف انشغال provider | تبقى الحجوزات/المراجع الأكاديمية اللازمة لتسوية تشغيل مأذونة |
| فيديو/صوت Zoom الأصلي | رابط مزود محمي، بلا نسخة وسائط محلية | سحب الإتاحة وحذف الرابط/metadata المحلية | لا حذف للأصل لدى العميل؛ الرابط الذي كُشف سابقًا يخضع لقيود Zoom |
| تفريغ Zoom | recordings.transcript مع revision/hash | محوه وتنقيح مرجع الملف | advanced؛ لا تنزيل URL يقدمه المستخدم؛ مصدر Zoom موثق فقط |
| فتح تسجيل | recording_opens | حذف سجلات فتح اتصال ملغى | opened_only؛ لا سجل مشاهدة كامل أو ساعات إكمال |
| مسودة AI ونسخة Odeiry | ai_drafts + response_data/messages للـrun المرتبط | مسح المحتوى والنص المستمد مع إبقاء قياس الاستخدام المنقح | advanced يثبت تنظيف المسودة/ردودها؛ لا نموذج مدرب على البيانات |
| مشتق AI طُبق في authoring | مسودة/نسخ تحرير تعليمية مستقلة لها مصدر | **policy_required**؛ لا محو تلقائي لتعديلات بشرية أو منشور مختلط | لم يكتمل مسار حذف مشتق منقح عبر جميع نسخ التأليف؛ مانع طرح خارجي |
| حضور أكاديمي آلي مستمد | attendance_records.metadata.zoom | الإجراء المعتمد اختياريًا delete_auto_preserve_human يحذف الآلي وينقح evidence لليدوي | دون قرار صريح تبقى purge policy_required؛ لا افتراض إعفاء لمجرد الجدول الأكاديمي |
| قرار يدوي/شهادة | الحضور اليدوي/شهادة أودير | حفظ القرار والسجل؛ تغيّر مصدره ينشئ مراجعة | certificates؛ لا إبطال شهادة خارج مسارها المعتمد |
| عميل ندوة مستقل/موافقة | contacts + مصدر وإسناد وموافقة | حذف فترات/روابط/هوية Zoom بالندوة؛ حفظ CRM المستقل بحسب سياسته | advanced؛ الموافقة والملف ليسا إيرادًا أو تسجيلًا أكاديميًا |
| دفع وتسجيل وقبول | accounting_core/academy المستقلة | لا حذف أو عكس من فصل Zoom | مقارنة أعداد المدفوعات/التسجيلات في lifecycle؛ ليس فحص إنتاج |
| CSV والـticket | report_exports/report_chunks | ساعة للناتج، دقيقتان للتذكرة، حذف عند الانتهاء/إلغاء التفويض | reports + HTTP؛ نسخة نزلها مستخدم خارج سيطرة التخزين |
| كاش المتصفح والخادم | no-store للروابط/الاستجابات الحساسة؛ no public cache | لا نسخ أسرار في localStorage؛ دليل أول استخدام فقط | UI/contracts؛ راجع CDN الفعلي وقت إعداد البيئة |
| logs والتدقيق | رموز خطأ/correlation وأفعال منقحة | لا أسرار أو تفريغ كامل؛ سياسة audit القائمة | لا ادعاء بمحو سجلات خارجية لم تُفحص |
| نسخ احتياطية/استعادة | بنية Supabase المعتمدة خارج التطبيق | يلزم مدة من مالكها وإعادة تطبيق سجل الحذف بعد الاستعادة | **لم يُختبر ولم يُعتمد**؛ runtime يرجع backupDeletion pending |

`advanced_purged_at` و`derived_attendance_purged_at` يمنعان إعادة الدوران حول طلبات مكتملة وحجب الطلبات الأحدث؛ `derivatives_need_review` يحفظ مانع مراجعة محتوى التأليف حتى بعد اعتماد حذف الحضور الآلي. اختبار 27 طلبًا يثبت استكمال دفعتين، واختبار المسودة المطبقة يثبت بقاء policy_required.

`v1_zoom_purge` يعمل في dispatch حتى عند إيقاف flag العام. `purge_requests` و`retention_runs` يسجلان النتيجة. بقاء policy_required أو backup policy pending يمنع وصف العملية بالحذف الشامل المكتمل. الاختبار يثبت التنظيف المحلي فقط؛ لا ينفذ طلب حذف حي ولا يتصرف في أصل عميل.

قبل إطلاق خارجي: اعتمد مصدر كل حقل، مدة الإتاحة، مشتقات التأليف، سجلات الأعمال/التدقيق، ومهلة مزود النسخ الاحتياطية. اختبر طلبًا اصطناعيًا يشمل نسخة تحرير مطبقة واستعادة احتياطية مأذونة. لا تؤجل هذه الخطوة إلى ما بعد تفعيل عميل حقيقي.
